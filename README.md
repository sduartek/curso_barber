# BarberApp ✂️

Aplicação web desenvolvida para gerenciamento e agendamento de horários em barbearias, permitindo autenticação de usuários, visualização de estabelecimentos e realização de agendamentos.

## 🚀 Tecnologias utilizadas

* Next.js
* React
* TypeScript
* Prisma
* NextAuth
* CSS
* Git/GitHub

## 📌 Funcionalidades

* Autenticação de usuários
* Listagem de barbearias
* Agendamento de horários
* Interface responsiva
* Organização modular de componentes
* Integração com banco de dados

## 🎯 Objetivo do projeto

Praticar conceitos de desenvolvimento full stack moderno, componentização, autenticação, integração de banco de dados e organização de aplicações utilizando o ecossistema React/Next.js.

## ▶️ Como executar

```bash
npm install
npm run dev
```
